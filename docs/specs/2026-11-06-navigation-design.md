# 搜尋、篩選與導覽翻新設計

日期：2026-11-06。狀態：owner 已授權「直接設計一版完善的篩選和導覽系統，不用討論」，本文件是依此做的決定。

## 意圖

owner 看過上線版後的原話：「現在整套導覽系統很差，側邊欄頁面空白，且篩選模式也很少（至少要能依照角色篩選），此外標題後方希望附上 XX 幾箱、混活等等資訊。請站在使用者操作角度想起。……也請注意不要落入按鈕地獄。」

站在讀者的角度，三件事最常發生：

1. 想找「某個角色的活動」或「某團第幾箱」，目前只能用團體篩選加肉眼。
2. 讀到一半離開，回來要從目錄一路點回去，側邊欄幫不上忙。
3. 想把某一期、某一話的連結丟給朋友，列是按鈕不是連結，長按沒反應，返回鍵也不會記住篩選。

## 目標

- 目錄列一眼看得出：這期是哪團第幾箱還是混活、什麼類型、幾話、能讀幾話、讀到哪。
- 能依角色篩選（單選），能依活動類型篩選，和既有的團體篩選並用。
- 搜尋同時找活動名、話數標題、期數、角色名、團體名。
- 篩選狀態寫在網址，返回、重新整理、分享都保留。
- 側邊欄在每一頁都有用：回到目錄、最近閱讀、上一話／下一話、上一期／下一期、團體捷徑。
- 所有「到某頁」的東西都是真的連結，可以長按、開新分頁、複製。

## 非目標

- 多選角色、依屬性或卡片篩選、排序切換（目前固定新到舊）。
- 全文搜尋台詞（素材不在 git，也不進瀏覽器儲存）。
- 閱讀頁本身的改動（分鏡、格子）。

## 反目標

- 按鈕地獄：目錄頁常駐可見的操作維持在「一個搜尋框、一列可橫捲的晶片」。角色和類型收在一個面板裡，平時只露出一顆「角色」晶片。
- 側邊欄長成設定頁：項目分「本頁導覽 → 活動目錄 → 最近閱讀 → 團體 → 設定」五段，每段不超過五項。

## 資料

### 每期的登場角色

`scripts/build_index.py` 多抓 Sekai-World TC master DB 的兩張表 `eventCards`、`cards`（同一個 GitHub 倉庫，不碰 storage.sekai.best），每期新增 `chars`：該期活動卡的角色 id，依 `eventCards` 順序去重。一般活動 5 人，World Link 最終章 26 人照列。沒有活動卡的期 `chars` 為空陣列。

### 箱數與標籤

前端 `catalog.ts` 計算，不進索引檔：

- `boxNo`：同一團體（`unit` 不是 `none`）的活動依 `date` 升冪、同日依 `id` 升冪，從 1 起編號。
- `eventLabel(e)`：
  - `type === 'world_bloom'` → `World Link`
  - `unit === 'none'` → `混活`
  - 其餘 → `${短名} 第${boxNo}箱`；短名：Leo/need、MMJ、VBS、WxS、25時。
- 類型短名：`marathon` → 馬拉松、`cheerful_carnival` → 嘉年華、`world_bloom` → World Link（標籤已是 World Link 時不重複顯示）。

### 最近閱讀

`localStorage` 新鍵 `recent`：`[{ sid, id, no, title }]`，進入閱讀頁時把該話移到最前，最多保留 5 筆。進度沿用既有 `pos:<sid>`。

## 目錄頁

```
台服活動劇情 · 183 期 · 目錄更新於 2026-11-06
┌ 搜尋活動、話數、角色 ─────────────────────┐
(全部)(Leo/need)(MMJ)(VBS)(WxS)(25時)(混活)(角色 ▾)
符合 12 期 · 清除篩選                 ← 只在有任何篩選時出現
──────────────────────────────────────────
▌Colors of Pure Sense                            #184
▌2026-10-31 · 25時 第20箱 · 馬拉松 · 8 話 · 可讀 8/8 · 讀到第 3 話
▌● 奏 ● 真冬 ● 繪名 ● 瑞希 ● 未來
```

- 團體晶片：行為不變（`unit` 等於該值；混活 = `none`，含 World Link）。晶片文字改用短名，省寬度。
- 「角色 ▾」晶片：開啟篩選面板。選了角色後晶片變成「● 一歌 ×」：點名字重開面板，點 × 清除角色。選了類型但沒選角色時晶片顯示「馬拉松 ×」之類。兩者都有時顯示「● 一歌 · 馬拉松 ×」，× 一次清掉面板裡的兩項。
- 篩選面板（底部抽出的面板，有遮罩，Esc 和遮罩可關）：
  - 「活動類型」：全部／馬拉松／嘉年華／World Link，單選晶片。
  - 「角色」：六組（五團 + VIRTUAL SINGER），每組一行，每人一顆圓形（角色色底、名字），單選；點選即套用並關閉面板。
  - 底部「清除」。
- 篩選語意：團體、角色、類型三者 AND；角色篩選找的是 `chars` 含該角色的期，所以混活也會出現，這是讀者預期的「某角色的活動」。
- 搜尋：不分大小寫，比對活動名、期數、話數標題、角色名（名、姓名）、團體名與短名。
- 列資訊：第二行依序 日期 · 標籤 · 類型 · N 話 · 可讀 n/N（有可讀才顯示）· 讀到第 k 話（有進度才顯示；全部讀完顯示「讀完」）。第三行登場角色：角色色點 + 名，最多顯示 8 人，超過顯示「等 26 人」。
- 空結果：「找不到符合的活動。」加一顆「清除篩選」。

### 網址狀態

`#library?unit=street&char=12&type=marathon&q=雪`。鍵缺省即不篩選；無任何篩選時網址是 `#library`。篩選改變用 `history.replaceState` 更新（不污染返回鍵），進入活動後按返回會回到同樣的篩選。`q` 用 `encodeURIComponent`。不認得的值視為未設定。

## 活動頁

```
第 184 期 · 25時 第20箱 · 馬拉松                ← header 標題
Colors of Pure Sense
2026-10-31 開始 · 8 話 · 可讀 8/8
● 奏 ● 真冬 ● 繪名 ● 瑞希 ● 未來
[ 繼續閱讀 第 3 話 ]  或  [ 從第 1 話開始 ]      ← 有可讀話數才出現
 1  比賽            閱讀
 2  失敗作品        讀到 40%  繼續閱讀
 ...
← 上一期 #183 交融的色彩一如昔日        下一期 #185 … →
```

- 「繼續閱讀」指向最後一話有進度且未讀完的話；全部讀完或沒進度時指向第 1 話。
- 上一期／下一期依索引順序（id 相鄰的上一筆／下一筆），日文或無劇本的期照列，點進去會看到「尚未提供」。

## 側邊欄（每一頁）

由上而下：

1. 頭：目前頁標題與副標（既有）。
2. 本頁導覽：閱讀頁 → 上一話、下一話、這期的話數列表；活動頁 → 上一期、下一期；目錄頁 → 無。
3. 活動目錄。
4. 最近閱讀：最多 3 筆，「第 184 期 第 3 話 迷惘的心 · 讀到 40%」，點了直接進閱讀頁。沒有紀錄時整段不顯示。
5. 團體：一行五顆色點晶片，連到 `#library?unit=…`。
6. 設定：黑白（只在閱讀頁，既有）。

## 連結

- 目錄列、話數列、上一話／下一話、上一期／下一期、側邊欄項目、最近閱讀、團體捷徑一律 `<a href="#…">`。`go()` 只留給程式導向（篩選面板選完、繼續閱讀按鈕）。
- 側邊欄裡的連結點了要先關側邊欄（既有的 `data-go` 機制改成對所有 `a` 生效）。

## 無障礙與行動裝置

- 面板 `role="dialog" aria-modal="true"`，開啟時焦點進面板，關閉後回到「角色」晶片。
- 晶片列維持橫向捲動；面板高度不超過視窗的 80%，內部可捲。
- 所有點擊目標至少 40 px 高。

## 留給實作者的

- 面板的動畫、圓形角色鈕的確切尺寸與字級。
- 空 `chars` 的期（舊資料或無卡活動）第三行直接省略。

- **篩選只剩搜尋框 + 團體晶片**（全部／Leo/need／MMJ／VBS／WxS／25時／混活）。角色面板、活動類型篩選、`char=`、`type=` 全部移除；網址只有 `#library?unit=&q=`。找角色用搜尋（名或姓名）。
